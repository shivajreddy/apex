# apex

Ultra-fast, ultra-lightweight launcher for Windows. Raycast, but native.

- Pure Win32 + Direct2D. No Electron, no webview, no runtime.
- Single small binary. Minimal RAM. Instant startup.

## Status

Early development.

## Build

```
cargo build --release
```

## Usage

- `Alt+Space` — toggle the launcher
- `Esc` — dismiss
